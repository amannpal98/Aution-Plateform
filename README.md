# 🔨 BidHub — Real-Time Auction Platform

A full-stack real-time bidding web application built with React, Node.js, Socket.IO, and MongoDB.

---

## 🚀 Tech Stack
- Frontend: React, Vite, Tailwind CSS  
- Backend: Node.js, Express.js  
- Database: MongoDB  
- Real-time: Socket.IO  
- Authentication: JWT + bcrypt  

---

## ⚙️ Setup

### Clone Repository
git clone https://github.com/amannpal98/Aution-Plateform.git 
cd auction-app  

### Backend Setup
cd server  
npm install  

Create `.env` file:
PORT=5000  
MONGO_URI=your_mongodb_url  
JWT_SECRET=your_secret_key  

Run backend:
npm run dev  

### Frontend Setup
cd client  
npm install  
npm run dev
